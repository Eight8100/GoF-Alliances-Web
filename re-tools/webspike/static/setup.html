GoFA Revival

A fan-made, work-in-progress revival of Galaxy on Fire: Alliances.

  1. This project ships none of the original game's files.
  2. Pick your own copy of the iOS game, version 1.16.1 (an .ipa file).
  3. The map, text, images and 3D models are copied out of it onto this computer, once. Nothing is uploaded to the internet.
Or type the path to an .ipa or an unpacked Dominion.app folder
Waiting for your .ipa.

  
The import takes a few minutes. You only need to do it once per copy of this project.
